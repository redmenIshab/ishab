# Stitch Design Board Snapshot

Local export of the Stitch project board for `redmenIshab`.

## Contents
- `project.summary.json`: Project identity and board instances.
- `design-system.summary.json`: Applied design system and theme tokens.
- `screens.manifest.json`: Screen metadata and remote preview links.
- `screens/*.html`: Local HTML exports for each screen.
- `*.raw.json`: Original MCP payload snapshots.
